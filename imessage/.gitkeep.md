# 依赖与运行数据（第一次启动前自行创建）
#
# imessage/bin/                  ← 编译产物 imessaged、imsg（BUILD.md 生成）
# imessage/apple-data/imessage-linux/
#     ├── IMDAppleServices         ← 自行获取，见 BUILD.md 的哈希校验
#     └── cert-1.0.plist
# imessage/state/                ← 0700，daemon 自己写（含等价密码，禁止提交/外传）
# imessage/bus/                  ← 0700，跨容器 session bus socket
# imessage/gw/data/              ← 0700，SQLite 队列
# imessage/gw/gw.env             ← 从 gw.env.example 复制，填入自己的密钥
# secrets/                       ← 0700，SSH 私钥（0600）+ ssh_config + known_hosts
#
# 建议一次性建好权限：
#   sudo install -d -m 700 -o 10001 -g 10001 imessage/state imessage/bus imessage/gw/data
#   sudo install -d -m 700 secrets
#   sudo chown 10001:10001 secrets/id_ed25519 secrets/ssh_config && sudo chmod 600 secrets/id_ed25519* secrets/ssh_config
